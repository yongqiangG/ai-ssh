# F2. AI 回复命令块完整卡片形态 + markdown 渲染

> 来源：AI-OPS-PRODUCT 功能池（迁移入档）。工具调用产生的最小命令块（命令行 + 可折叠输出 + 成败徽标 + 在终端执行）已随 Tool 调用闭环交付；本条是完整三动作卡片形态。

- **交互**：AI 回复中的 shell 代码块渲染为命令卡片，带三个动作：**插入终端**（预填当前激活终端的输入行，不回车）、**复制**、**解释**（追问该命令逐段含义）。
- **价值**：AI 的输出直接变成可用的操作，闭环最后一公里。
- **技术要点**：消息内容 markdown 解析；「插入终端」经 terminalManager 向激活会话写入命令文本（不含换行符）。
