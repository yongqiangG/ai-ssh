# F6. 危险命令防呆（覆盖用户手输的前端统一拦截层）

> 来源：AI-OPS-PRODUCT 功能池（迁移入档）。agent 工具侧黑名单（挡模型手滑）与 CommandBlock 执行前 confirm 已交付（ADR 0002 §6 + B1 确认门）；本条定义的是覆盖**用户手输命令**的前端统一拦截层。

- **交互**：识别高危模式（`rm -rf` 变体、`drop database`、裸 `chmod -R 777`、`mkfs`、`> /dev/sda` 等规则库）→ 回车时弹确认卡片：显示命令、危险原因、影响范围提示，需显式点击「仍然执行」。
- **价值**：「AI 不会帮用户删库」的信任感是 AI 运维产品的生命线；该防线同时覆盖 AI 生成与人工输入。
- **技术要点**：前端拦截回车 + 规则匹配即可起步；规则库做成可配置（允许用户关闭单条规则或整体）。拦截点在「回车提交前」，与 F2「插入不执行」、F4「预填不执行」共同构成三层安全设计。
