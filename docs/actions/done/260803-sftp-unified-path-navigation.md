# 260803 · SFTP 本地与远程统一路径导航

## 阶段 1：路径模型与状态边界

**目标**：建立可测试的远程相对路径归一化、本地绝对路径/盘符处理和目录状态模型。

**设计**：
- 远程路径解析以当前面板目录为基准，保留 `~`、`~/...`、`/...` 锚点并规范化 `.` / `..`。
- 本地路径仅接受 Windows 盘符绝对路径和 UNC 路径；盘符根作为路径导航的根节点。
- 远程目录按连接保存当前会话状态；本地目录独立保存；新连接或重启恢复远程 `~`。
- 把路径解析、远程面包屑和本地面包屑收敛为纯函数，先以单元测试锁定边界。

**验收标准**：远程相对路径、家目录、SFTP 根、父目录不会越过根；本地盘符、UNC 和父级路径生成稳定；目录状态不串连接。

**测试用例**：
- `.`、`..`、连续斜杠、`~`、`~/logs`、`/var/log` 的远程解析。
- 远程根和家目录面包屑、Windows 盘符根、UNC 面包屑。
- 连接 A/B 切换、首次连接、应用会话内恢复和本地目录独立性。

**验证**：`sftpStore.test.ts` 覆盖远程相对路径、根/家目录、Windows/UNC 路径、按连接记忆和本地/远程乱序请求；专用 store 测试 12/12 通过。
**状态**：已完成

## 阶段 2：统一路径导航界面

**目标**：本地与远程使用同一套路径工具栏，完成根目录、上一级、面包屑、编辑态路径和盘符切换。

**设计**：
- 抽取共享路径导航表现层：上一级按钮、根/盘符入口、面包屑、路径编辑态、Enter 提交和 Esc 取消。
- 远程显示 SFTP `/` 与 `~` 入口；本地盘符根可展开为可读取逻辑盘列表。
- 移除本地原生“选择目录”按钮；本地编辑态支持盘符路径与 UNC 路径。
- 路径跳转失败时维持原目录、保留输入并展示错误，不静默回退。

**验收标准**：两侧工具栏结构与操作顺序一致；远程可回 `/` 和跳任意目录；本地可直接切盘和跳 UNC；不再出现独立于面包屑的目录选择按钮。

**测试用例**：
- 点击根、上一级、任意面包屑和路径编辑提交。
- 远程相对路径跳转、无权限路径错误保持。
- 本地盘符菜单、盘符根禁用上一级、UNC 输入和错误展示。

**验证**：新增 `PathNavigator` 及回归测试；路径导航相关测试 19/19 通过。远程根 `/`、家目录 `~`、上一级、路径编辑和本地盘符下拉均有组件断言；原本独立的本地“选择目录”入口已从 `DirListView`/`SftpPanel` 移除。
**状态**：已完成

## 阶段 3：导航并发与传输回归

**目标**：保证快速导航、列表刷新和进行中的传输互不污染。

**设计**：
- 为目录请求增加序列号或取消/忽略旧请求机制，最后一次导航才能提交列表状态。
- 传输在启动时捕获完整本地/远程路径；切换当前目录不修改传输目标。
- 传输完成后只刷新仍可见的目标目录，不强制切换用户浏览位置。
- 保持现有拖拽、搜索、覆盖确认和传输进度行为。

**验收标准**：乱序响应不会覆盖新目录；导航中上传/下载目标稳定；当前目录与搜索状态不被后台刷新错误重置。

**测试用例**：
- 两次远程导航逆序返回，最终状态属于最后一次请求。
- 传输启动后切换目录，断言请求仍使用原始完整路径。
- 目标目录可见/不可见时分别验证刷新和不跳转。

**验证**：store 回归覆盖上传/下载启动时捕获完整路径；目标目录不可见时不调用当前目录刷新；远程和本地请求均以序列号保证最后一次导航优先。
**状态**：已完成
